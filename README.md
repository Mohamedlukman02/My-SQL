# MySQL SchoolDB Practice

This repository contains a basic MySQL database practice task.

## Task: School Database Management

### Operations Performed

1. Created a database named `schoolDB`

2. Selected the database using `USE`

3. Created a `students` table with columns:
   - id
   - name
   - age
   - grade

4. Inserted student records into the table

5. Retrieved data using SELECT query

6. Dropped the database after practice

## SQL Concepts Used

- CREATE DATABASE
- USE DATABASE
- CREATE TABLE
- INSERT INTO
- SELECT
- DROP DATABASE
